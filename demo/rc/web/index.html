THE DRIVER

Every button is one real request to magmux. This page holds only the read-only view token; the actions that type are performed by demo/rc/serve.ts, which holds the session token, and what appears below is magmux's own status and body — including the 403s.

press an action — the request and the response both land here
Read-only stream. This page's WebSocket holds magmux's --view-token-file token, which input, send, open_pane and close_pane all refuse with forbidden. The driver panel is an escalation, not a detail: serve.ts holds the session token and types on this page's behalf, so whoever can reach this page's origin and its per-run path can type into the shell rather than merely watch it. Same guards, bigger prize — RC_DEMO_WEB_DRIVER=0 removes the endpoint and this panel. Press f to give the terminal the whole page, Esc to come back.
