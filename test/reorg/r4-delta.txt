# r4-delta.txt: the complete list of R4's hand edits, as prove-r4.sh sees them.
#
# prove-r4.sh applies r4.sed to the pre-R4 sources, normalises both sides
# (headers and blank lines out, protocol./client. qualifiers stripped, blanks
# collapsed), and compares them as sorted MULTISETS of lines. Every line below
# exists on only one side: "- " only before R4, "+ " only after. The proof
# passes only if the actual delta is exactly this file (# lines ignored), so a
# new difference anywhere in the group fails it.
#
# Because the comparison is of sorted lines, a hunk's lines are scattered
# below; these are the hunks, and every delta line belongs to one of them:
#
#  1. mux keeps its old names as aliases of protocol's, so no call site in mux
#     changed: `const sockProtocol = Version`, the thirteen
#     `sockCodeX = CodeX` lines and the comment over them, `type sockErr =
#     Error` and its comment, a sockErrf that returns Errf(...), and a
#     one-line verbErrCode over CodeOf. The definitions themselves moved to
#     protocol verbatim (r4.sed renames them), so verbErrCode's doc line now
#     exists twice: once as CodeOf's, once over the alias ("+ // verbErrCode").
#
#  2. New in protocol, not moved from anywhere: Errf's doc comment, the second
#     line of CodeOf's doc, the Event* constants (sockEvents in mux now spells
#     the names through them; that line is renamed by r4.sed) and their
#     comments, and OpClass / OpSpec, which the architecture assigns to R4 and
#     nothing uses yet. Two of the "+ const (" / "+ )" pairs are the events
#     block and mux's alias block (protocol's codes block replaces the old one).
#
#  3. client: sockErrCode is deleted ("- func sockErrCode", its body) because
#     mcp now reads a failed request's code with protocol.CodeOf; to make that
#     true, sockRequestError gains an Unwrap to the *protocol.Error it carries
#     (three comment lines and the one-line func). Its Error() text is
#     unchanged. Session gains `State()`, the accessor mcp reads the pane view
#     through instead of the unexported field.
#
#  4. The JSON helpers evStr, evInt and evBool, with their "── JSON helpers"
#     banner, are needed on BOTH sides (mcp decodes tool results with them;
#     client decodes events), so they are copied, not moved. They account for
#     every "+ case", "+ return", "+ v, ok", "+ if !ok {" and six of the six
#     "+ }": 2 (evStr) + 3 (evInt) + 1 (evBool) + 1 (sockErrf's wrapper) +
#     1 (OpSpec) - 2 (sockErrCode) = 6.
#
#  5. TestNoCouldNotDetectString (mux/theme_test.go) scans the source of the
#     packages lifted out of mux by path, so it now also globs ../client and
#     ../protocol, and its comment says so; otherwise it would silently stop
#     scanning the lines that moved from mcp into client.
#
